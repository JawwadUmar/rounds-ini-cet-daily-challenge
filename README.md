# Rounds — INICET Daily Challenge

A static React and TypeScript application for INICET preparation. It offers five daily questions and an illustrated library of ten May/November papers from 2020–2025, with subject browsing, search, figures, locked answers, and solutions. Daily challenges track streaks, calendar activity, and shareable results. Progress stays in the browser.

## Run locally

Requires Node.js 22+ and npm.

```powershell
npm ci --cache .cache/npm
npm run dev
```

Open **http://127.0.0.1:4173**. The local HTTP process is a development tool, not an application backend.

```powershell
npm run validate:bank
npm test
npm run build
npm run test:e2e
```

Browser tests use Playwright Chromium. If the browser is missing, run `npx playwright install chromium`.

## Static deployment

`npm run build` emits the app, year-wise data modules, fonts, and question figures in `dist/`. Upload the entire directory to a static host. Relative asset paths support deployment in a subdirectory. HTTPS enables native sharing and clipboard access on supported browsers. All application assets and question data are bundled locally; the app has no runtime API calls or analytics.

## Question bank and source

The bank contains **1,983 questions** from ten sittings in the supplied MEDINK compilation: May 2025; May and November 2024; May and November 2023; May and November 2022; May and November 2021; and November 2020. It includes 409 figures for 404 questions. Each question retains its printed sitting, question number, answer, explanation, and source pages. The compilation’s wording and keys have not been independently authenticated.

All imported questions enter a 397-day daily rotation. Each question appears once before the final day’s two schedule-padding repeats. Five different subjects are selected per day. Difficulty is marked as estimated Medium because the compilation does not supply editorial ratings. Nine entries with duplicated choices or figure-based layouts that cannot be scored reliably remain read-only.

The 19 subject names are normalized to the app’s canonical labels. Annual paper modules combine that year’s sittings and preserve the original May/November label in each question. See [PDF import and verification](docs/PDF_IMPORT.md) for the counts, pairing rules, and reproduction steps.

## Dates and progress

- The archive starts **1 January 2026**. Earlier dates are retrospective practice; they do not imply the app was live then.
- `src/data/schedule-v1.json` is the frozen 1,985-ID schedule. Its 397-day cycle begins on 1 January 2026 and covers all 1,983 unique questions before the final-day repeats.
- A date and schedule edition always select the same ordered questions, independent of browser session, timezone travel, or file order.
- The schedule is generated by `scripts/freeze-full-pyq-schedule.mjs`. Re-freezing it changes historical question assignments.

## Completion, streaks, and storage

The saved IANA study timezone is initialized from the browser and remains fixed. A day is complete when all five questions are confirmed. Submitted answers are locked. Catch-up challenges remain available but do not earn streak credit.

Progress is stored in IndexedDB, with a localStorage fallback. Export and import are available in Settings. Browser-local data can be lost when site data is cleared, private browsing ends, or storage is evicted; export a backup regularly. The app does not promise an authenticated clock, guaranteed offline reopening, or protection against deliberate local-data edits.
