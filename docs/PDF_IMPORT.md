## Pairing and transcription

The question and solution sheets are physically interleaved and sometimes out of order. The extractor identifies the sitting from each sheet’s repeated heading, distinguishes question sheets by their hidden answer text, and sorts sheets by their first numbered anchor. It pairs the printed key and rationale with the question, retaining the physical question and solution pages.

Annual library IDs are unique across multiple sittings. Each entry keeps `paperSession` and `printedNumber` so the interface can show the sitting and the number printed in the book. Yearly totals are 2025: 200, 2024: 400, 2023: 398, 2022: 399, 2021: 402, and 2020: 184.

The May 2022 question sheet repeats question 67 as question 68, while its answer section contains 199 entries. Both duplicate question entries are preserved as printed and made read-only; question 68 uses its embedded answer, and following entries pair with the preceding solution number. Other duplicated choices and figure-choice questions are also marked read-only when their printed layout does not support reliable scoring. No missing per-option commentary is invented.

The TypeScript entry point for a year loads both of its May and November papers in printed order, grouped under the app’s 19 canonical subjects. The subject index uses the year-wide library numbering. All 1,983 imported questions join the daily rotation; questions without editorial ratings are marked with an estimated Medium difficulty. The library and daily bank share each question’s text rather than duplicating it.

Figures are extracted from original embedded image bytes and grouped under `public/assets/images/pyq/{year}/{sitting}/`. Repeated 74×74 and 57×57 QR graphics are excluded. The figure map retains page coordinates and question ownership for audit.

## Reproduction

An ordinary app build uses the checked-in TypeScript modules and figure files. To re-extract this edition, install PyMuPDF for Python, then run from the repository root:

```powershell
$paperFile = 'INICET Yearwise Exam Papers 2025-2020_unlocked.pdf'
python -X utf8 scripts/pyq/extract.py $paperFile
python -X utf8 scripts/extract-pyq-images.py $paperFile
python -X utf8 scripts/pyq/populate.py
```

Intermediate coordinates, alternate text, and the figure map are written under `.cache/`. The daily rotation is generated by `node scripts/freeze-full-pyq-schedule.mjs` after importing the paper data.
