# Question sourcing

The active question bank is transcribed from the supplied MEDINK compilation, **INICET Yearwise Exam Papers 2025–2020**, May 2026 edition. The import retains the book’s wording, answer keys, explanations, printed sitting and question number, and physical PDF page locators.

The book itself cautions that its information may contain errors. This project has not independently authenticated the papers or clinically reviewed every answer. Source entries with visibly duplicated choices or figure-based options that cannot be scored consistently remain read-only. See [PDF import and verification](PDF_IMPORT.md) for the edition fingerprint, extraction method, and known pairing exception.
